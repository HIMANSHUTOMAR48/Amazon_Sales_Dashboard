# Amazon Sales Dashboard – Advanced Excel

## Project Overview
This project presents an interactive Amazon Sales Dashboard created using Microsoft Excel to analyze product and category-level sales data.

## Tools Used
- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- Excel formulas and KPI cards

## Dashboard Features
- Total Value KPI
- Total Brand Count
- Category Count
- Average Quantity
- Category-wise sales analysis
- Product and brand analysis
- Interactive slicers for filtering data

## Key Objectives
- Analyze product sales across categories.
- Compare sales performance across brands and products.
- Present key metrics in a visual dashboard.
- Make reporting easier through interactive filters.

## Files Included
- `Amazon_Sales_Dashboard.xlsx` – Excel dashboard and analysis workbook.
- `dashboard.png` – Dashboard preview.

## How to Use
Download the Excel workbook and open it in Microsoft Excel. Use the available slicers to filter the dashboard.
